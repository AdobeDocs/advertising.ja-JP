# Baidu、GGL、MS、YJPのキャンペーンおよび広告グループ設定の「負のキーワード」フィールド

**[!UICONTROL Negative Keywords]:** （オプション）検索した際に広告をトリガーしないキーワード。 マイナス記号（`-`）なしで次の構文を使用します。

* 負の部分一致：`keyword` （[!DNL Microsoft Advertising]ではサポートされていません）
* 否定的な語句の一致：`"keyword"`
* 負の完全一致：`[keyword]`

複数の値をコンマで区切るか、別々の行に入力します。 1回の操作で最大2000個のネガティブキーワードを入力またはペーストできます。

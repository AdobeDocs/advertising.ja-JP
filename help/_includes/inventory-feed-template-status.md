# テキスト広告テンプレート – ステータス

**[!UICONTROL Status]:** テンプレートの状態：*[!UICONTROL Active]*、*[!UICONTROL Paused]*、または&#x200B;*[!UICONTROL Deleted]*。

フィードデータは、アクティブなテンプレートを通じてのみ自動的に伝達できます。 ただし、一時停止したテンプレートを通じてデータを手動で伝達できます。

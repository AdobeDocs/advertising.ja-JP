# グリッドおよびACM テンプレートのGGLおよびMS ショッピングキャンペーン設定のMerchant ID フィールド

**[!UICONTROL Merchant ID]:** （ショッピングキャンペーンとオーディエンスキャンペーンは加盟店フィードにリンクされています）製品がキャンペーンに使用されている加盟店アカウントの顧客ID。

加盟店センターストアにリンクされた[!DNL Microsoft Advertising]件のオーディエンスキャンペーンの場合、検索アカウントにリンクされているすべてのストアのリストから[!UICONTROL Merchant ID]を選択します。 キャンペーンをストアにリンクして設定を保存すると、このオプションを変更することはできません。

# レコードの追加、更新、削除に必要なデータ

次の表に、コンポーネントレコードの各タイプを追加、編集、または削除する際に、必須、オプション、または適用されないフィールドを示します。 アクションにフィールドが適用されない場合、フィールドに入力された値は無視されます。

>[!NOTE]
>
>* すべてのテキスト列の値では、大文字と小文字が区別されます。
>* 新しいレコードを作成し、すべての必須データフィールドの値を含まない場合、これらのフィールドの一部には、指定されたデフォルト値が割り当てられます。
>* 以下に指定されていないフィールドの場合、広告ネットワークのデフォルト値が使用されます。
>* [!UICONTROL Download Bulksheet] ダイアログで使用可能なバルクシート行のリストについては、「[広告ネットワーク別バルクシート行](/help/search-social-commerce/legacy-ui/campaign-management/bulksheets/bulksheet-download.md#bulksheet-rows-by-ad-network)」を参照してください。

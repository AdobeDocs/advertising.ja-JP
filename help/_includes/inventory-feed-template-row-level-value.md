# ショッピング広告テンプレートの「行レベル値」フィールド

**[!UICONTROL Row Level Value]:** （[!UICONTROL Product Type]および[!UICONTROL Category]階層のみ）フィード値が大文字[`>`]で区切られている場合に、フィードから使用する値。 例えば、層が2の[!UICONTROL Row Level Value]を使用して`Product Type:L2=[Category2]`をターゲットとし、のフィード値が
「`[Category2]`」列は「`Software>Graphics>Image Processing`」で、「グラフィック」がターゲットになっています。 デフォルトでは、製品タイプレベルまたはカテゴリーレベルと同じレベルが選択されています。

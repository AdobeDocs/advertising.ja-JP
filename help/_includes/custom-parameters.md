# GGLおよびMS キャンペーン設定、MS広告グループ設定、MS マルチメディアおよびレスポンシブ広告設定のカスタムパラメーターフィールド

**[!UICONTROL Custom Parameters]:** （オプション、[!DNL Microsoft Advertising]のオーディエンスキャンペーンにのみ適用）最大3つのカスタムパラメーターの名前と値のペア。 名前の最大長は英数字16文字です。値の最大長は埋め込みパラメーターを含む200文字です。

カスタムパラメーター名は、エンティティとその子エンティティのトラッキングテンプレートに含めることができます。 ユーザーが関連する広告をクリックすると、広告ネットワークはパラメーター名を定義されたパラメーター値に置き換えます。 例えば、顧客パラメーター`{_color}=red`を作成し、トラッキングテンプレートに`http://tracker.example.com/?color={_color}&u={lpurl}`が含まれている場合、ユーザーが広告をクリックすると、カラーパラメーターに「赤」が挿入されます。

広告グループまたは（[!DNL Microsoft Advertising]のみ）広告レベルのカスタムパラメーターがキャンペーンレベルを上書きします
同じ名前のカスタムパラメーター。

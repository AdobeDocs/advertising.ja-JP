# （新しいUI）目的の設定の書き出し

*Beta機能*

1つ以上の目標の設定を[!DNL Microsoft Excel]個のワークシート ファイルにエクスポートします。 各目的の設定には、各指標とそのソース、指標タイプ（目標またはアシスト）、モバイル以外とモバイルの重み、および推奨されるモバイル以外とモバイルの重みが含まれます。

複数の目的を書き出す場合、書き出しは、各目的に対する個別のワークシートを含むZIP ファイルで構成されます。

1. メインメニューで、**[!UICONTROL Goals]>[!UICONTROL Objectives]**&#x200B;をクリックします。

1. 書き出す各オブジェクトの横にあるチェックボックスをオンにします。

1. 一括操作ツールバーで、**[!UICONTROL Export Objectives]**&#x200B;をクリックします。

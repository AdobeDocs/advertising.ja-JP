# [!DNL Google Ads]さんが動的検索広告の設定を拡張しました

動的検索広告（DSA）は、検索専用キャンペーンの[!DNL Google Ads]件の動的広告グループでのみ使用できます。 広告ネットワークは、見出しを動的に生成し、動的な検索広告のランディングページと表示URLを選択し、最終的なURLを自動的に生成します。

アカウントごとの[広告制限](https://support.google.com/google-ads/answer/6372658?hl=en)について、[!DNL Google Ads]のヘルプを参照してください。

>[!NOTE]
>
>広告コピーを変更すると、既存の広告が削除され、同じプロパティを持つ新しい広告が作成されます。

## [!UICONTROL Basic Settings]

*新しい広告のみ*

**[!UICONTROL Network]:**&#x200B;広告ネットワーク。

**[!UICONTROL Account]:**&#x200B;広告ネットワークアカウント。

**[!UICONTROL Campaign]:** キャンペーン。

**[!UICONTROL Ad Group]:**&#x200B;広告グループ。

## [!UICONTROL Expanded Dynamic Search Ad Details]

**[!UICONTROL Description Line 1]、[!UICONTROL Description Line 2]:**&#x200B;広告の本文。 2行目はオプションです。 最大長の合計は80文字です。

**[!UICONTROL Status]:**&#x200B;広告ステータス：*[!UICONTROL Active]*&#x200B;または&#x200B;*[!UICONTROL Paused]*。

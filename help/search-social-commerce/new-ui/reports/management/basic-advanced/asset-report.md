# [!UICONTROL Asset Report]

*[!DNL Google Ads] アカウントの[!DNL AI Max]対応キャンペーンにのみ適用*

[!UICONTROL Asset Report]には、[!DNL AI Max]が有効なキャンペーンで該当するAI生成アセットごとに、アセットレベルで追跡された[!DNL Google]のコンバージョンデータが、コスト、クリック、および（オプション）が含まれます。 このレポートには、Adobe Analyticsのコンバージョンは含まれていません。 このレポートを使用して、保持、一時停止、置換するアセットに優先順位を付けます。<!-- Not included as of 7/22/26: You can optionally include advertiser-specific label classifications. -->

デフォルトでは、データには、該当するアセットごとに1行（ロゴ、画像、動画、見出しなど）が含まれ、指定された日付範囲の時間単位ごとに少なくとも1つのトラッキング指標が含まれます。 行は、デフォルトではキャンペーン名で昇順になっています。

[!DNL Google Ads]のデータは、通常、過去36か月間ご利用いただけます。

* [!UICONTROL Account]
